# Archive

How ScoreAnim was built up to 2026-07-30. Nothing in here is part of a
normal session's reading — it is kept because it records measurements and
reasoning that are still true, not because it describes how we work now.

- `ROADMAP.md` — the beta roadmap and the two-track process (retired
  2026-07-30). The milestone scope sections say what M1–M7 were.
- `PHASES.md` — the frozen v0.1-alpha build history.
- `briefs/` — the milestone briefs (M1–M6). Each one holds the spike
  measurements and the decisions behind a milestone; when you need to
  know why something works the way it does, the brief usually says.
- The loose `*_BRIEF.md` files — the same thing for the alpha-era phases,
  the adapter refactor and the live-timing epic.

The current process is in CLAUDE.md. The current rules are in CLAUDE.md
with the long form in `docs/RULES.md`. The current design is in
`docs/ARCHITECTURE.md`.
